Idealised Tree Category Models

This preview shows the source category OBJ models used by the tree stage. Species are mapped to these category shapes, then per-tree DBH scales trunk radius with trunk_radius_m = DBH_m / 2. Height and crown radius use explicit tags when available; otherwise they use the category defaults shown below.

Drag to rotate all models. Use the mouse wheel or zoom buttons to zoom. Source catalog: tree_categories.json. Species mapping: docs/assets/data/florence_opendata/trees_diameter/species_category_mapping.json.
